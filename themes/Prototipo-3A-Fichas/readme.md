Diapositiva 3 ("Productos propios"): los links son fichas grises con borde superior verde en grilla de dos columnas, con el ícono verde en un círculo negro. Las fichas se dan vuelta al entrar y el borde verde se dibuja.

Basado en la diapositiva 3 de la presentación "Antares Proyectos IT 2026" (Montserrat, #111111, #F2F2F2, verde #7BD51D).

Pure CSS: works without "Allow custom code in themes". Respects "reduce motion".
